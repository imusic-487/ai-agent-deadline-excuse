## The entry

> Sorry, my context compacted mid-task and the summary kept the plan, the code and the confidence, but summarized the deadline out of existence.

## How it works

`main.py` (Python 3, standard library only) writes that single line to `/output/entry.txt` and checks it is 1–200 characters first. No network, no dependencies.

```sh
python3 main.py
```
